Universe RP databases

Universe RP keeps its data in two SQLite database files.

FileWhat it holds
accounts.dbPlayer accounts and characters, the characters' skills, weapons and items, and the news.
lua.dbWhat Lua plugins store: plugin_kv holds each plugin's own data (Storage), char_kv its data per character (Storage.char; char_id is the character's CharID in accounts.db).

Where they are

In this folder, when the server is started with the Universe RP host launchers. Otherwise in <fs_homepath>/UniverseRP/database/.

Keep them private. accounts.db holds every account's password as plain text. Don't share the file or upload it to a website. The viewer below reads it inside your browser and uploads nothing.

Look inside

Open SQLite Viewer
  1. Drop accounts.db or lua.db from this folder on the viewer (or click it and pick the file).
  2. Pick a table, or run an SQL query. Tables can be saved as CSV.

The viewer only views: nothing done in it is saved to the file.

While the server runs, the newest Lua data may not be in lua.db yet: the server keeps it in memory and writes it every 30 seconds and at the end of a map, and the latest writes can sit in lua.db-wal beside it, which the viewer doesn't read. For an exact view, stop the server first.

SQLite Viewer is a free, third-party tool by Juraj Novák. Source: github.com/inloop/sqlite-viewer
