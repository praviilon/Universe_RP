What it is

Roleplay, built in

Universe RP turns Jedi Academy multiplayer into a home for roleplay communities.

Every player has an account with characters that keep their level, skills, credits, sabers and looks. Chat goes as far as a voice would carry, with actions, descriptions, shouts, whispers and alien languages. Admins and builders shape the world in game: they place props, NPCs, lights and effects, lock doors to chosen players and save it all for the next session.

It continues GalaxyRP by Alex, rebuilt to run natively on the modern TaystJK engine, in 64-bit, on Windows, Linux and macOS.

Runs on TaystJK

Universe RP runs natively on TaystJK, a modern Jedi Academy engine. Coming from OpenJK or the original game? Install TaystJK first: it uses your own Jedi Academy files. Then launch the game and the server with the scripts that come with the mod.
