All downloads

The Client package is for playing: the client modules, the assets and the play launcher. The Full package adds what a server needs: the server module, universe_rp_server.cfg, the host launchers and the data folders. Older versions are on the releases page.

UNIVERSE RP

A roleplaying mod for Star Wars Jedi Knight: Jedi Academy multiplayer, by Pra Viilon. It builds on GalaxyRP (Alex and team), zyk's mod, JAPro, TaystJK, EternalJK, OpenJK and OJP.
