Cvar calculator

Some server settings are bit values: one number for a list of choices. Tick what you want and copy the line into universe_rp_server.cfg, or paste a value from it to see what it means.

  • Weapons
  • Force powers
  • Userinfo checks
  • Votes
  • Game flags
  • New account admin powers

The same calculator is in the Full package as UniverseRP/universe_rp_calculator.html, for use offline. Back to the server guide.

UNIVERSE RP

A roleplaying mod for Star Wars Jedi Knight: Jedi Academy multiplayer, by Pra Viilon. It builds on GalaxyRP (Alex and team), zyk's mod, JAPro, TaystJK, EternalJK, OpenJK and OJP.
