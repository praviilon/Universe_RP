Run a server

The Full package has everything a Universe RP server needs. Set it up, start it with the script, and claim the admin account.

  1. Install TaystJK and the Full package

    Install TaystJK into the game folder as for playing: its archive includes the dedicated server (taystjkded). Then extract the Universe RP Full package into the same folder. Download both.

    The UniverseRP folder then holds, besides the client files:

    • universe_rp_server.cfg: the server's settings;
    • universe_rp_host and universe_rp_host_autorestart (.bat, .sh or .command): the launchers;
    • database/, entities/, remaps/, duelarena/, meleearena/: the server's data;
    • universe_rp_calculator.html: the cvar calculator, also online.

  2. Set up the config

    Open the fresh UniverseRP/universe_rp_server.cfg in a text editor. Every setting has a comment saying what it does. At least:

    • sv_hostname: your server's name in the server browser.
    • rconpassword: change it from the default.
    • g_motd and rp_screen_message: what players see on joining.
    • The map rotation at the end (universerp_1, universerp_2).

    Don't reuse an old version's config. Settings were added, renamed and given new ranges; start from the fresh file and carry your values over by hand.

  3. Start the server

    Run universe_rp_host for your system from the UniverseRP folder; on Linux, ./universe_rp_host.sh. Or run universe_rp_host_autorestart: it brings the server back up if it crashes, logs each restart to universe_rp_restart.log, and stops on a clean /quit.

    • Players connect on UDP port 29070: forward it on your router and allow it through the firewall.
    • The port, the server's address and LAN or internet mode are set at the top of the launcher.

  4. Claim the admin account

    A fresh database has one account with every admin power: login admin, password admin. Connect to your server, then:

    /login admin admin
/changepassword <a new password>

    Give other players admin powers with /adminup <player> <number or all>; /adminlist lists the powers. New accounts get the powers set in rp_default_account_permissions (none by default).

Settings worth knowing

The config has about 20 sections, from passwords and gametypes to weapon damage and mini-games. These are the Universe RP settings most servers look at first.

CvarDefaultWhat it does
rp_pluginRequired1Players without the Universe RP client: 0 nothing, 1 a warning, 2 kept in spectator
rp_loginRequired01 keeps players who are not logged in as spectators
rp_seamlesslogin1Log in and switch characters without a respawn; 0 forces one
rp_downed_timer30Seconds a downed player stays down (30-100); 0 switches the downed system off
rp_downed_invulnerability_timer10Seconds of protection after getting up (up to 30)
rp_afk_time120Seconds without input before a player goes AFK; 0 switches AFK and /away off
rp_allow_emotes1/emote, /anim, /wehug, /wekiss: 0 off, 1 on, 2 on except in private duels
rp_allow_cosmetics10 hides every hat and cape; each character's choice is kept
rp_ledgeGrab1Ledge grab for players with the Universe RP client
rp_allow_grapple_hook2Grappling hook: 0 nobody, 1 logged-out players and skill holders, 2 skill holders only
rp_dice_roll_cooldown3000Milliseconds between /roll and /flipcoin uses
rp_rpg_max_level100The highest character level
rp_logical_entities1The extra pool for logical entities; leave it on
g_weaponDisable, g_forcePowerDisable0Bit values: work them out with the calculator

Data

Backups and upgrades

What to back up

  • database/accounts.db: accounts, characters, skills, items and news, in one SQLite file. Any SQLite browser opens it.
  • entities/, remaps/ and locks/: what admins built, per map.
  • duelarena/ and meleearena/: the mini-game arenas.
  • logs/: the game log and the security log.

Coming from GalaxyRP

Universe RP lives in its own UniverseRP folder, so an old GalaxyRP server can stay untouched beside it. To carry your server over, copy its database and preset folders (entities, remaps, locks, duelarena, meleearena) into UniverseRP, and set up the fresh config.

UNIVERSE RP

A roleplaying mod for Star Wars Jedi Knight: Jedi Academy multiplayer, by Pra Viilon. It builds on GalaxyRP (Alex and team), zyk's mod, JAPro, TaystJK, EternalJK, OpenJK and OJP.
