Play

Join a server

Universe RP runs on the TaystJK engine and your own copy of Jedi Academy. Four steps, about five minutes.

  1. Install TaystJK

    You need Jedi Academy itself: the game's GameData/base folder with assets0.pk3 to assets3.pk3. Download the TaystJK archive for your system and extract it into GameData:

    • Delete the OpenJK executables there first, so you don't start the wrong one.
    • Or keep OpenJK, and make a separate folder for TaystJK with a copy of base in it.

    TaystJK's own install guide has the details for each system, such as the libraries Linux needs.

  2. Add Universe RP

    Extract the Universe RP Client package into the same folder. It holds one folder, UniverseRP, which ends up next to the TaystJK executables:

    GameData/
├── base/                 your Jedi Academy files
├── taystjk.x86_64.exe    the TaystJK engine
└── UniverseRP/
    ├── universe_rp_play.bat
    └── ...

    On Linux the engine is taystjk.x86_64 and the launcher universe_rp_play.sh; on macOS, taystjk.app and universe_rp_play.command.

  3. Launch with the script

    Start the game with the launcher in the UniverseRP folder:

    • Windows: double-click universe_rp_play.bat.
    • Linux: run ./universe_rp_play.sh from a terminal in the UniverseRP folder.
    • macOS: double-click universe_rp_play.command. If macOS refuses to open it the first time, right-click it and choose Open.

    It asks one question: press Enter to go to the main menu, or paste a server's address (for example 203.0.113.7:29070) to connect straight away.

    The script finds the right TaystJK build for your computer, starts it with Universe RP as the mod, and keeps your settings, screenshots and downloads together in the game folder. Starting TaystJK without it can leave your settings in TaystJK's own folder instead.

  4. Your first minutes in game

    • Open the console with ~ (or Shift + Esc).
    • Make an account: /new <login> <password>. Next time, /login <login> <password>.
    • Make a character: /char new <name>.
    • Talk: the chat key (T) speaks in character, at the range a voice carries; the team chat key (Y) goes to your allies, or out of character if you have none. Start a message with /me for an action.
    • Press Esc and open the Universe RP menu for your character, skills, shop, camera and the Extras.
    • /list commands lists every command, /list chat the chat modifiers. The features page explains them.

If something is off

Good to know

"Could not find taystjk..."

The launcher looks for TaystJK one folder up from UniverseRP. Check that the TaystJK files and the UniverseRP folder sit side by side, and that you took the TaystJK build for your system.

The server asks for its client

Universe RP servers expect the Universe RP client files. Install the Client package as above and launch with the script.

Coming from GalaxyRP

The mod's folder is now UniverseRP. To keep your binds and settings, copy taystjk.cfg from your old GalaxyRP folder into UniverseRP.

Linux on ARM

TaystJK publishes no Linux ARM64 build, so build it yourself with its build guide. The launcher looks for taystjk.arm64.

UNIVERSE RP

A roleplaying mod for Star Wars Jedi Knight: Jedi Academy multiplayer, by Pra Viilon. It builds on GalaxyRP (Alex and team), zyk's mod, JAPro, TaystJK, EternalJK, OpenJK and OJP.
